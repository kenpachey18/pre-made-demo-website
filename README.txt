PICKLEBALL BOOKING WEBSITE
HTML / CSS / JAVASCRIPT VERSION

FILES
- index.html: customer booking website
- admin.html: administrator portal
- styles.css: all website and admin styling
- script.js: customer booking behavior
- admin.js: administrator behavior

HOW TO USE
1. Keep all five files in the same folder.
2. Open index.html in a modern web browser.
3. Open admin.html to manage bookings and availability.
